# Traffic Signal Optimizer — Dynamic Direct Web Version

Flow:
1. Open `login.html`
2. Login with `admin` / `admin123`
3. Open Home
4. Go to Dashboard
5. Change vehicles, hour, source, destination, and zone vehicles
6. Click `Optimize Traffic`

No Flask, no Python server, and no localhost are required.

This is a front-end academic prototype. The calculations are demonstration rules for the project UI, not real-world traffic-control standards.
